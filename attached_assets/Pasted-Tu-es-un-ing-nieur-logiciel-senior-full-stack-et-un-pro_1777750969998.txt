Tu es un ingénieur logiciel senior full-stack et un product designer senior.

Ta mission est de concevoir et développer une application web SaaS complète appelée VisaFlow France pour gérer et accompagner les étudiants d’Afrique francophone admis dans des écoles privées françaises (INSEEC, ECE, etc.) dans toute leur procédure de visa étudiant France.

Objectif produit
Construire une plateforme web moderne permettant de suivre de A à Z la procédure d’un étudiant depuis son admission dans une école privée française jusqu’à l’obtention du visa puis l’arrivée en France.

Le produit doit avoir 3 espaces majeurs :

Espace étudiant

Espace équipe / conseiller

Espace admin

L’application doit être pensée comme un véritable outil opérationnel interne + portail étudiant.

Stack technique imposée
Frontend : Next.js 14+ avec App Router

Langage : TypeScript

UI : Tailwind CSS

Components : shadcn/ui ou bibliothèque équivalente propre

Backend : Next.js server actions ou API routes

Base de données : PostgreSQL avec Prisma ORM

Authentification : NextAuth/Auth.js ou Clerk

Stockage fichiers : S3 compatible ou Supabase Storage

Emails : Resend

Validation : Zod

State management : React Query + state local propre

Logs erreurs : Sentry

Contraintes d’architecture
architecture propre, modulaire et maintenable,

séparation claire entre domaine métier, UI et accès données,

RBAC strict,

code typé,

validations côté serveur,

audit logs,

responsive mobile-first,

design premium mais sobre,

prêt pour production.

Utilisateurs et rôles
1. Étudiant
Peut :

créer son compte,

compléter son profil,

voir son dashboard,

suivre ses étapes,

voir ses checklists,

uploader ses documents,

répondre aux commentaires,

voir ses tâches et rendez-vous,

recevoir des notifications.

2. Conseiller / Advisor
Peut :

voir ses étudiants assignés,

accéder aux fiches dossiers,

commenter,

demander des corrections,

valider ou rejeter des documents,

changer certains statuts,

gérer ses tâches,

suivre les urgences.

3. Reviewer
Peut :

revoir les documents,

valider ou rejeter,

laisser des commentaires internes,

participer au contrôle qualité du dossier.

4. Admin
Peut :

tout voir,

gérer utilisateurs et rôles,

configurer workflows,

configurer checklists,

gérer templates,

voir analytics,

voir audit logs,

forcer certains statuts avec justification.

5. Superadmin
Même droits que admin + paramètres système avancés.
